Row & Stitch - Support

Row & Stitch is a knitting and crochet row counter for iOS. Count rows and stitches, track unlimited projects, set reminders every N rows, and keep your notes in one place.

Help

  • Counting: tap + to add a row, - to undo. Long-press for options.
  • Reminders: set a reminder inside a project to be nudged every N rows - great for increases, cables and color changes.
  • Backup: export your projects from Settings and import them on any device.
  • Pro: a one-time purchase unlocks extra counters, pattern steps, row markers, high contrast, extra colors and removes ads. Use "Restore purchases" on the Pro screen if you reinstall.
